🐞 Escape Bug – Draw to Trap Game

Escape Bug is a simple and interactive browser game where the player must stop a moving bug from escaping by drawing walls on the screen.

The bug moves automatically inside the game area. The player uses a finger (on mobile) or mouse (on PC) to draw lines that act as barriers. The goal is to trap the bug before it reaches the border of the screen.

The game includes a score system, limited ink for drawing, increasing speed over time, and a restart option. As time passes, the bug becomes faster, making the game more challenging.

This project is built using:

HTML

CSS

JavaScript (Canvas API)

The game works on both mobile and desktop browsers without any external libraries.

It is a beginner-friendly project that demonstrates:

Canvas drawing

Event handling (mouse & touch)

Collision detection

Basic game loop logic
